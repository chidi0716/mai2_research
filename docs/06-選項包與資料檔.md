# 06 選項包與資料檔（StreamingAssets、曲目、收藏品）

> 來源：
> - 反編譯 SDEZ 1.70 `Assembly-CSharp.dll`（標「反編譯」的都核對過），並對照本機 `StreamingAssets\A000`。
> - NGO 銘牌包的資料檔。
> - [MaiChartManager](https://github.com/MuNET-OSS/MaiChartManager)（GPLv3，commit `72e4f01`）、[AquaMai](https://github.com/MewoLab/AquaMai)（Apache-2.0，commit `77f6eb1`）的原始碼：只讀了原始碼，依授權只記做法。

## 1. 選項包資料夾（`A???` / `N???`）

反編譯 `DataManager.GetDirs`、`IsTargetDirName`：

- 遊戲掃 `Sinmai_Data\StreamingAssets\` 底下名稱符合 `A???` 的資料夾：**`A` + 3 位數字**（`int.TryParse` 後面 3 個字元），排序後依序讀。
- 接著掃 `AppImage.OptionMountRootPath` 底下的 `N???`（排序後接在 `A???` 後面）。
  - 原版的值沒在 `Assembly-CSharp` 裡確認。
  - 裝了 AquaMai 時，`OptionLoadFix`（預設開）把它改成 `StreamingAssets` 本身，所以 `StreamingAssets\N???` 也會被讀（見 [11](11-AquaMai功能與入口.md)）。
- 例：本機 1.70 有 `A000`（本體）、`A100`、`A999`、`N100`、`N999`。
- **後面的資料夾覆蓋前面的**：
  - XML 資料（`LoadData`）以 ID 為鍵，`outSerializes[id] = ...`，同 ID 後讀的勝出；`disable = true` 的條目最後被移除。
  - 影片（`MovieData\*.dat`）、音效（`SoundData\*.awb`、`Mai2.acf`）以檔名為鍵，後讀的勝出。
  - AssetBundle（`AssetBundleImages\**\*.ab`）以 `AssetBundleImages/` 之後的相對路徑為鍵，後讀的勝出。
- `DataConfig.xml`：每個資料夾都可以有一份，取 `version` 最大的那份（反編譯 `SetupConfig`）。MaiChartManager 從 `A000\DataConfig.xml` 的 `/DataConfig/version/minor` 讀遊戲版本（1.70 → 70）。
- 所以加內容 = 新開一個編號沒被用掉的 `Axxx`，放同樣的子資料夾結構，不動原檔。NGO 銘牌包用 `A588`，maimai-ngo 的搭檔資料用 `A500`。MaiChartManager 新增時取現有最大編號 + 1，超過 999 就從 999 往下找空的。
- **「官方」和「自製」怎麼分**（AquaMai `HideSelfMadeCharts`）：資料夾裡有 `DataConfig.xml` 或 `OfficialChartsMark.txt` 的算官方，其他包裡的歌都算自製譜。

## 2. 資料種類一覽（本機 1.70 `A000`）

`A000` 底下的資料夾就是遊戲所有可以用選項包覆蓋的資料種類：

- **曲目**：`music`、`musicGenre`、`musicVersion`、`musicLevel`、`musicDifficulty`、`musicClearRank`、`musicGroup`、`musicNameSort`、`releasetag`
- **收藏品**：`plate`、`title`、`icon`、`frame`、`partner`、`partnerCloseness`、`photoFrame`、`collectionGenre`、`collectionType`
- **成長與地圖**：`chara`、`charaAwake`、`charaGenre`、`map`、`mapBonusMusic`、`mapColor`、`mapTreasure`
- **活動與挑戰**：`event`、`loginBonus`、`mission`、`missionMusicCondition`、`course`、`courseMode`、`challenge`、`class`、`udemaeBoss`、`udemaeSeasonEvent`、`udemaeSeasonReward`
- **CiRCLE**：`circleBonus`、`circlePointEvent`、`circlePointReward`、`festa`、`festaSide`、`festaRankingReward`
- **KaleidxScope**：`kaleidxScopeCourse`、`kaleidxScopeGate`、`kaleidxScopeGatePhase`、`kaleidxScopeGateExLifePhase`、`kaleidxScopeKey`、`kaleidxScopeMusicGroup`
- **通行證與商店**：`passChara`、`passCharaGroup`、`passPack`、`passType`、`shopItem`、`shopItemCategory`、`ticket`
- **其他**：`hiddenItem`、`information`、`scoreRanking`
- **資源**：
  - `AssetBundleImages`：`chara frame frame_s framemask framepattern fst_image icon jacket jacket_s map nameplate navichara partner passbg passchara photoframe scoreranking specialeffect tabtitle`…
  - `SoundData`、`MovieData`、`DataConfig.xml`

## 3. 一首歌由哪些檔案組成（已對照 1.70 `A000`）

以曲目 ID `11234`（DX 譜）為例。非 DX ID = `ID % 10000` = `1234`：

| 內容 | 路徑 | 備註 |
|---|---|---|
| 曲目資料 | `A???\music\music011234\Music.xml` | 資料夾名用完整 ID |
| 譜面 | 同資料夾 `011234_00.ma2`～`_05.ma2` | `notesData` 有 6 格（BASIC～Re:MASTER、宴會場） |
| 音訊 | `A???\SoundData\music001234.acb` + `.awb` | 用**非 DX ID**，STD / DX 共用 |
| 影片（PV） | `A???\MovieData\001234.dat` | USM，用非 DX ID |
| 大封面 | `A???\AssetBundleImages\jacket\ui_jacket_001234.ab` | 遊戲取 `Jacket/UI_Jacket_xxxxxx.png`，找不到用 `000000` |
| 小封面 | `A???\AssetBundleImages\jacket_s\ui_jacket_001234_s.ab` | 遊戲取 `Jacket_S/UI_Jacket_xxxxxx_S.png`（`GetJacketThumbTexture2D`） |

- **ID 規則**：STD < 10000；DX = STD + 10000；宴會場 ≥ 100000。`Music.xml` 的 `movieName.id`、`cueName.id`、`artistName.id` 都用非 DX ID。
- **`Music.xml` 主要欄位**：
  - 識別：`dataName`、`name`（{id, str}）、`sortName`、`artistName`
  - 分類：`genreName`（分類 ID）、`AddVersion`（版本分類 ID）、`version`（例 22001）、`releaseTagName`、`netOpenName`
  - 曲目：`bpm`、`movieName`、`cueName`、`longMusic`（`1` = 長版，吃 2 首）
  - 解鎖：`eventName` / `eventName2` / `subEventName`、`lockType` / `subLockType`
  - 宴會場：`utageKanjiName`、`comment`、`utagePlayStyle`
  - 其他：`disable`
- **每個譜面**（`notesData/Notes`）：`file/path`、`level`、`levelDecimal`、`musicLevelID`（顯示用等級）、`maxNotes`、`isEnable`、`notesDesigner`。
- **自製譜慣例**（MaiChartManager）：
  - `eventName` 用 1（無期限常時解放），歌一開始就能玩。
  - 作者 / 譜師 ID 填 999。
  - 工具自己的資料放在 `X-MCM/` 節點（遊戲讀 XML 時會忽略未知節點）。
- **ID 衝突**：不同選項包裡的同名 `music00xxxx.acb/.awb`、`00xxxx.dat` 會互相蓋掉（後讀的勝出），選 ID 前要掃描全部 `A???`（MaiChartManager 的衝突檢查就是做這件事）。
- 封面、PV、音訊的格式與製作見 [07](07-貼圖影片與換皮.md)、[08](08-音效系統.md)。

## 4. 收藏品 XML（以銘牌為例）

- 路徑：`A???\plate\plate<6 位數 ID>\Plate.xml`（排序檔 `plate\PlateSort.xml`）。其他收藏品同理：`partner\partner<ID>\Partner.xml`、`title`、`icon`、`frame`。
- 根元素 `PlateData`，主要欄位：
  - 識別：`dataName`、`netOpenName`、`releaseTagName`、`name`（{id, str}，id 就是銘牌 ID）
  - 分類與顯示：`genre`（例 5 = その他）、`isDefault`、`dispCond`（`None` / `Lock` …）、`normText`（鎖住時顯示的說明）、`priority`
  - 解鎖：`eventName`（{id, str}）、`relConds`（解鎖條件）
  - 其他：`disable`
- **貼圖檔名是遊戲自己決定的**（反編譯 `DataManager.LoadPlate`）：`fileName = "NamePlate/UI_Plate_" + id.ToString("D6") + ".png"`，XML 裡的 `<fileName>` 沒有作用。
- **收藏畫面顯示規則**（反編譯 `CollectionProcess`）：玩家擁有，或 `dispCond == None`，或 `disable` 時才列出；ID 2、3 是固定的「預設 / 隨機」項目。
- 新搭檔另見 [09](09-加入自訂內容.md#maimai-ngopartnerlive2d的做法)（`Partner.xml` 要 UTF-8 含 BOM、`isDefault = true`）。

### 讓自訂收藏品「打一首歌就自動解鎖」

NGO 銘牌包的做法（已用反編譯驗證）：

- `eventName.id = 1`（「無期限常時解放」），`relConds.category = Track`，`condition0.kindTrack = DIFFICULTY`、`difficultyId = ANY`，其餘條件 `None`。
- `CollectionAchieve.Configure` 收集 `relConds` 裡有 Track / Credit / Total 條件的銘牌、稱號、icon、搭檔、frame，以 `eventName.id` 分組；`Initialize` 只保留 `EventManager.IsOpenEvent(eventId)` 的事件。
- 每首歌結束時 `NextTrackProcess` 呼叫 `CollectionAchieve.BuildParameter` → `CheckNewPlate` / `CheckNewTitle` …。`AchieveTrack.FuncDifficulty` 遇到 `ANY` 直接回傳 true，所以任何難度打完一首就拿到。
- 好處：不用 Harmony，走遊戲自己的取得流程（有「NEW」標記）；壞處：取得紀錄會上傳到伺服器。

## 5. 工具與周邊檔案

- **MaiChartManager**：自製譜管理工具（C# ASP.NET Core + WebView2 + Vue）。
  - 功能：改曲目資料、管理分類和版本、檢查 ID 衝突；匯入 Simai / maidata、匯出成選項包；處理 ACB/AWB 與 USM / MP4；安裝 AquaMai 並編輯設定。
  - 它**不注入遊戲**，只讀寫 `StreamingAssets\A???` 的檔案和 `AquaMai.toml`，所以它的程式碼就是一份「選項包格式說明」。
  - 選項包資料夾用正規式 `^[A-Z](\d{3})$` 辨認。
  - 「遊戲資源連結」工具：用 Windows Junction 把另一套遊戲的 `AssetBundleImages`、`MovieData`、`SoundData` 連到目前這套的 `A000`，省空間；只連目標不存在的項目，來源只讀。
- **AquaMai 相關檔案**：`Mods\AquaMai.dll`、`AquaMai.toml`（備份 `AquaMai.toml.bak`）。MuMod：`Mods\MuMod.dll`、`MuMod.toml`，快取在 `LocalAssets\MuMod.cache`。
- AquaMai 全部功能的入口目錄見 [11](11-AquaMai功能與入口.md)。
