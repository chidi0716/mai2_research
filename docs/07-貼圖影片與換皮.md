# 07 貼圖、影片與換皮

> 來源：
> - 反編譯 SDEZ 1.70 `Assembly-CSharp.dll`（標「反編譯」的都核對過）。
> - NGO 铭牌包（`NgoPlates.dll` 反編譯 + 資料檔）、[maimai-ngo](https://github.com/TOTO-git-q/maimai-ngo) 的說明文件。標「NGO 實測」的是對方記錄的量測結果，我們沒有自己重現。
> - [AquaMai](https://github.com/MewoLab/AquaMai)（Apache-2.0）、[MaiChartManager](https://github.com/MuNET-OSS/MaiChartManager)（GPLv3）的原始碼：只讀了原始碼，依授權只記做法。

## 1. 遊戲怎麼載入貼圖（反編譯）

- `AssetManager` 建構時把 `StreamingAssets/A000/AssetBundleImages/` 交給 `AssetBundleManager`；實際的 bundle 路徑由 `OptionDataManager.GetAssetBundlePath` 決定（覆蓋規則見 [06](06-選項包與資料檔.md#1-選項包資料夾a--n)）。
- `AssetManager.LoadAsset<T>(path)`：路徑先轉小寫，去掉副檔名後查快取的 bundle。
- 取圖方法：

| 方法 | 找不到時 |
|---|---|
| `GetJacketTexture2D(int)` → `(string)`（`MusicData.jacketFile`） | `Jacket/UI_Jacket_000000.png` |
| `GetJacketThumbTexture2D(int)` → `(string)`（`thumbnailName`） | `Jacket_S/UI_Jacket_000000_S.png` |
| `GetPlateTexture2D(int id)` → `GetPlateTexture2D(string filename)` | `NamePlate/UI_Plate_000000.png` |
| `GetFrameTexture2D(int)` / `(string)` | `Frame/UI_Frame_000000.png` |
| `GetPartnerTexture2D(int)` / `(string)` | `Partner/UI_PartnerIcon_000000.png` |
| `GetIconTexture2D(string)` | `Icon/UI_Icon_000000.png` |

  `int` 版本：`DataManager.GetPlate(id)` 為 null 時，隨機項目（`GameCommonSetting.IsRandom(id)`）用 `..._00000{id}.png`，否則用預設圖。
- 遊戲本身只讀 `*.ab`。直接放 PNG 要靠 AquaMai 的 `LoadLocalImages`（第 2 節）。
- **小方法會被 Mono JIT 內聯**（NGO 實測）：
  - 例如 `GetPartnerTexture2D(string)` 從 `(int)` 版本被呼叫時，掛在 `(string)` 上的補丁不會觸發。要掛呼叫端真的用的那個多載，或往下一層掛比較大的方法。
  - NgoPlates 掛 `GetPlateTexture2D(string)` 的 Postfix 能用，是因為其他地方直接用檔名呼叫它（實測可用；內聯的條件沒有逐一確認）。

## 2. AquaMai 的 `LoadLocalImages`（直讀圖片，原始碼確認）

設定段 `[GameSystem.Assets.LoadLocalImages]`，預設開啟，設定 `ImageAssetsDir`（預設 `LocalAssets`）。

- **讀取時機**：Prefix `DataManager.LoadMusicBase`，用 Harmony 參數 `____targetDirs` 拿到遊戲的選項包清單（`A???` / `N???`）。
- **掃描的資料夾**：每個包的 `AssetBundleImages\{jacket, frame, nameplate, framemask, framepattern, icon, chara, partner}`、`AssetBundleImages\map\sprite\bg\*`、`Common\Sprites\Tab\Title` 的 png / jpg。
  - 檔名去掉 `ui_jacket_`、`ui_plate_` 等前綴，後面 6 位數就是 ID。
  - 後讀的包覆蓋前面的。
- **`LocalAssets`**：可以同時在遊戲根目錄和各選項包裡，依檔名合併（`AquaMai.Core.Helpers.LocalAssets`）。封面優先用 `LocalAssets\<ID>.png`。
- **換圖入口**：`TargetMethods` 一次掛多個方法，用 Prefix 回傳自己的 `Texture2D`（`new Texture2D(1,1,RGBA32,false)` + `LoadImage`）：
  - `AssetManager.GetJacketTexture2D(string)`、`GetJacketThumbTexture2D(string)`（沒有 `jacket_s` 圖時，同一張圖也拿來當小封面）
  - `GetPlateTexture2D(string)`、`GetFrameTexture2D(string)`、`GetIconTexture2D(string)`
  - 以及 frame mask / pattern、chara、partner 的取圖方法
  - 所以第 5 節 NgoPlates 的 Postfix 拿到的 `__result` 已經是 AquaMai 讀的 PNG。
- **分類標題圖**（`UI_CMN_TabTitle_<ID>`）：
  - 遊戲直接用 `Resources.Load<Sprite>` 載入。AquaMai 原始碼的註解寫：掛泛型 `Resources.Load<Sprite>` 會黑屏，掛 `AssetBundleManager.LoadAsset` 會記憶體錯誤。
  - 所以它改成遊戲載入後自己換 Sprite。MaiChartManager 自訂分類圖時把 `FileName` 設成 `UI_CMN_TabTitle_<ID>`，圖放在 `LocalAssets`。

## 3. 封面

- **官方格式**：400×400 BC7 的 Texture2D AssetBundle（檔名規則見 [06](06-選項包與資料檔.md#3-一首歌由哪些檔案組成已對照-170-a000)）。
- **長邊限制在 400**（MaiChartManager）：3000×3000 RGBA32 一張就要 34 MB 顯存，選曲時同步載入會掉幀。
- **不用 Unity 也能產生 AB**：MaiChartManager 自己寫 UnityFS 檔頭（版本 `2018.4.7f1`），把 RGBA32 Texture2D 包進去。container 路徑：
  - 大封面：`assets/assetbundle/jacket/ui_jacket_<id>.png`
  - 小封面：`assets/assetbundle/jacket_s/ui_jacket_<id>_s.png`
- **用 AquaMai 直讀圖片就不用 AB**。MaiChartManager 判斷封面的優先順序：
  1. `LocalAssets\<非DX ID 6 位>.png/.jpg/.jpeg`
  2. `A???\AssetBundleImages\jacket\ui_jacket_<ID>.png`（「假 AB」）
  3. `.ab`

## 4. 影片（PV）與音訊

- **PV**：遊戲讀 `MovieData\<非DX ID>.dat`（USM）。
- **AquaMai `MovieLoader`**（直讀 PV，預設開）：
  - 播放順序：遊戲自帶 PV → `MovieData\*.mp4`（或設定的路徑）→ 用封面當背景。
  - 入口：`DataManager.LoadMusicBase`（掃 mp4）、`GameCtrl.Initialize`、`GameMonitor.SetMovieMaterial`、`MovieController.Play` / `Pause` / `GetMovieWidth` / `GetMovieHeight`。
- **MaiChartManager 轉影片**：用 FFmpeg 轉 H264 / VP9，再包成 USM（WannaCRI）。影片不放音訊，音樂在 ACB 裡。
- **音訊**：用 SonicAudioTools / XV2-Tools 產生 `music<非DX ID>.acb/.awb`。格式見 [08](08-音效系統.md)。

## 5. 動態銘牌（NgoPlates 的做法）

銘牌本身仍是靜態 PNG（[06](06-選項包與資料檔.md#4-收藏品-xml以銘牌為例)、第 1～2 節），mod 只負責讓它動：

- **入口**：Postfix `AssetManager.GetPlateTexture2D(string filename)`（`[HarmonyPriority(0)]`，排在其他 Postfix 之後），用正規式 `UI_Plate_(\d+)\.png` 取 ID，有動畫資料就把 `__result` 換成自己的 `Texture2D`。之後每幀用 `Graphics.CopyTexture(下一格, 那張貼圖)` 改內容；遊戲手上的引用不變，所以不用找 UI 物件。
- **畫格格式**：原始 BC7 區塊直接接在一起（沒有檔頭），一格 720×116 → (720/4)×(116/4)×16 = **83,520 bytes**；檔案長度必須是它的整數倍。`new Texture2D(720, 116, TextureFormat.BC7, false)` + `LoadRawTextureData(ptr, 83520)` + `Apply(false, true)`。Unity 的原始資料列是**由下往上**。
- **載入**：背景執行緒只讀檔（`File.ReadAllBytes`），主執行緒每幀做幾格貼圖（打歌中 2 格、其他 8 格），全部做好才開始播。啟動時檢查 `SystemInfo.SupportsTextureFormat(BC7)` 與 `copyTextureSupport`，不支援就維持靜態。
- **切換狀態**：Postfix `ProcessManager.AddProcess(ProcessBase, byte)`，看 `process.GetType().Name`：`GameProcess` → 打歌狀態；`MusicSelectProcess`、`EntryProcess`、`AdvertiseProcess` → 一般狀態。12 fps，用 `Time.unscaledTime` 計時。
- **開關**：補丁類別的 `Prepare()` 回傳「資料夾存在」，刪掉 `LocalAssets\NgoPlates` 就整個不掛。任何例外 → 停用並保留目前畫面，不讓遊戲崩。

## 6. 直接改遊戲資源檔（maimai-ngo 換皮的做法）

maimai-ngo 的外觀幾乎都是寫進遊戲檔案，不是執行期替換（執行期替換會先閃一下原圖，而且每幀都有成本）。以下為 NGO 實測：

- **位置**：
  - UI 貼圖、Sprite（網格、rect）、`Image` 顏色、Prefab 數值、材質、粒子、3D 選單背景都在 `Sinmai_Data\resources.assets`（+ `.resS`）。
  - 導航角色（結算 / 選曲的熊）、角色圖在 `StreamingAssets\A000\AssetBundleImages\...\*.ab`（例 `navichara\prefab\ui_navichara_00.ab`、`chara\ui_chara_<id>.ab`）。
  - 分類顏色等在 StreamingAssets 的 XML。
- **工具**：UnityPy（`TypeTreeGenerator("2018.4.7f1")` + `load_local_dll_folder(Managed)` 才讀得到 MonoBehaviour）。
  - 要讀**遊戲資料夾裡那份**，備份檔在別處時外部參照會斷。
  - 同一個物件一次執行只能讀改存一次（第二次會從原始檔重讀，蓋掉第一次的修改）。
  - UnityPy 是延遲讀取：先 `env.file.save()` 產生完整輸出，寫成 `.new`、檢查大小，再在遊戲關閉時覆蓋。
  - 貼圖保持原名、原尺寸、原格式；像素會從 `.resS` 搬進 `.assets`（約 67 MB → 175 MB）。BC7 編碼用 `etcpak`，解碼用 `texture2ddecoder.decode_bc7`（`etcpak.decompress_bc7` 在他們的環境會失敗）。
- **畫之前先看原格式**：
  - 很多面板貼圖是白色遮罩，顏色由 `Image.color` 或程式上色；在上色的貼圖畫彩色會變髒，要改的是顏色。
  - 9-slice 的邊框列要照原本的保留。
  - 原版 Sprite 的網格是沿著原圖描邊的，換成形狀不同的圖會被裁掉，要改成整張四邊形或放大 `textureRect`。
  - 選中分頁是「彩色底圖 + 白色剪影疊圖（遊戲調它的 alpha 做閃爍）」兩層。
  - `Null_Selector_ColorBase._colors` 依難度索引，只有 index 7（分類藍 `#0A87F0`）可以改，其他是難度色。這是資源物件，`Assembly-CSharp` 裡沒有同名類別。
- **會出事的修改**：改 Sprite 的 `m_SortingLayer` 會讓待機畫面崩潰（要調順序請改材質 render queue，例如 2450）；MeshRenderer 的 sorting layer 改了沒效果。
- **3D 背景**：原版 Loop 動畫不驅動任何 Transform，「飄動」來自 shader 與粒子；要動就調粒子系統。
- **字型**：Unity 2018 不能從硬碟載 TTF；他們把像素字型的位元組寫進遊戲的 LiberationSans Font 物件，再在 `TextMeshProUGUI.OnEnable` 建動態 SDF 字型。AquaMai 的 `Fonts`（預設開）則是掛 `TextMeshProUGUI.Awake` 加回退字型。
- **發布方式**：安裝器逐個物件核對原值（`old`）再寫新值（`new`），不符就不寫；先備份（含 SHA-256），可重複執行、可解除安裝。這樣 repo 裡不必放遊戲檔案。

## 7. 執行期換圖的入口（各入口已用反編譯確認存在）

maimai-ngo 用到的：

| 時機 | 入口 | 用途 |
|---|---|---|
| 換畫面 | `ProcessManager.AddProcess(ProcessBase, byte)` Postfix | 判斷目前畫面（比 `OnStart` 早一步，一個入口就涵蓋全部 Process） |
| 待機 | `AdvertiseProcess.OnUpdate` | 加速 SEGA / ALL.Net 標誌（直接略過的話標題畫布不會出現，畫面變黑） |
| 任何 `Image` | `Image.OnEnable`、`Image.OnPopulateMesh`、`Image.sprite` setter | 換圖、頂點上色（給程式上色的貼圖） |
| 任何 TMP 文字 | `TextMeshProUGUI.OnEnable` | 換字型 |
| 選單背景 | `BGController.Awake`、`SubBGController.Initialize(int, bool)` | 換背景 |
| 選曲 | `MusicSelectProcess.OnStart/OnUpdate/OnRelease`、`SoundManager.PreviewPlay(int)`、`MusicSelectMonitor.ScrollMusicLeft/Right` | 版面、搭檔反應 |
| 隱藏店內匹配分類 | `MusicSelectProcess.SetConnectData` 後拿掉該分類、`IsConnectStart` / `IsConnectStop` 回「沒變化」 | **不可以略過 `PartyExec`**：NORMAL 模式是靠它把 START 轉成開始打歌 |
| 自由模式倒數 | `PleaseWaitMonitor.SetTime(int, int)` | 隱藏 / 換掉凍結的 10:00 |
| 歌曲開始卡片 | `TrackStartProcess.OnStart` | 換動畫 |
| 結算 | `ResultMonitor.SetStartData`、`TouchPartnerCharacter()`、`ResultTimelineManager.SetData` | 搭檔、評級動畫 |
| 導航角色動畫 | `NavigationCharacter.Play(NavigationAnime, float)` | 把原版狀態對應到自己的動作 |
| 搭檔房間 | `PartnerRoom.CreatePartner(int partnerId)` | 自訂搭檔 |
| 上傳畫面 | `UserDataULProcess.OnStart` | 隱藏 `DataSave/Chara`（隨機吉祥物都在這個群組） |
| 觸控 | `IO.TouchPanel.GameInputLog.TriggerOn(uint, InputManager.TouchPanelArea)`（internal，用 `AccessTools.TypeByName`） | `InputManager.GetTouchPanelAreaDown` 太小會被內聯 |

AquaMai 的做法（原始碼）：
- **全場景換圖**（`ResourcesOverride`，作者標「危險功能」）：Postfix `Graphic.Rebuild`、`CanvasScaler.OnEnable`，依 `sprite.name` / `texture.name` 查自己的圖替換。每次重建都會跑，注意 [10](10-效能與測試.md) 的 `Object.name` 配置問題。
- 音符皮膚（`CustomSkins`）、按鈕（`CustomButton`）、Logo（`CustomLogo`）等外觀功能的入口見 [11](11-AquaMai功能與入口.md#fancy外觀)。

自訂搭檔另見 [09](09-加入自訂內容.md#5-伙伴旅行伙伴動畫)。
