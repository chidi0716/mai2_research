# 13 自製譜與選項包管理（MaiChartManager / AquaMai 的做法）

> 來源：
> - [MuNET-OSS/MaiChartManager](https://github.com/MuNET-OSS/MaiChartManager)（GPLv3，commit `72e4f01`，2026-11-08）
> - [MewoLab/AquaMai](https://github.com/MewoLab/AquaMai)（Apache-2.0，commit `77f6eb1`，2026-10-31）
>
> 兩邊都只讀了原始碼，沒有執行。檔名規則已對照本機 SDEZ 1.70 的 `A000` 和反編譯。依授權只記做法和遊戲入口，不抄程式碼。

## 1. MaiChartManager 是什麼

- 自製譜管理工具（C# ASP.NET Core + WebView2 + Vue）：
  - 改曲目資料、管理分類和版本、檢查 ID 衝突
  - 匯入 Simai / maidata，匯出成選項包
  - 處理音訊（ACB/AWB）和影片（USM / MP4）
  - 安裝 AquaMai 並編輯設定
- 它**不注入遊戲**，只讀寫 `Sinmai_Data\StreamingAssets\A???` 的檔案和 `AquaMai.toml`。所以它的程式碼就是一份「選項包格式說明」。
- 選項包資料夾用正規式 `^[A-Z](\d{3})$` 辨認。新增時取現有最大編號 + 1，超過 999 就從 999 往下找空的。遊戲本身只認 `A???` 和 `N???`，見 [10](10-資源與選項包.md#1-選項包資料夾a--n)。
- 遊戲版本從 `A000\DataConfig.xml` 的 `/DataConfig/version/minor` 讀（1.70 → 70）。

## 2. 一首歌由哪些檔案組成（已對照 1.70 `A000`）

以曲目 ID `11234`（DX 譜）為例。非 DX ID = `ID % 10000` = `1234`：

| 內容 | 路徑 | 備註 |
|---|---|---|
| 曲目資料 | `A???\music\music011234\Music.xml` | 資料夾名用完整 ID |
| 譜面 | 同資料夾 `011234_00.ma2`～`_05.ma2` | `notesData` 有 6 格（BASIC～Re:MASTER、宴會場） |
| 音訊 | `A???\SoundData\music001234.acb` + `.awb` | 用**非 DX ID**，STD / DX 共用 |
| 影片（PV） | `A???\MovieData\001234.dat` | USM，用非 DX ID |
| 大封面 | `A???\AssetBundleImages\jacket\ui_jacket_001234.ab` | 遊戲取 `Jacket/UI_Jacket_xxxxxx.png`，找不到用 `000000` |
| 小封面 | `A???\AssetBundleImages\jacket_s\ui_jacket_001234_s.ab` | 遊戲取 `Jacket_S/UI_Jacket_xxxxxx_S.png`（`GetJacketThumbTexture2D`） |

- **ID 規則**：STD < 10000；DX = STD + 10000；宴會場 ≥ 100000。`Music.xml` 的 `movieName.id`、`cueName.id`、`artistName.id` 都用非 DX ID。
- **`Music.xml` 主要欄位**：
  - 識別：`dataName`、`name`（{id, str}）、`sortName`、`artistName`
  - 分類：`genreName`（分類 ID）、`AddVersion`（版本分類 ID）、`version`（例 22001）、`releaseTagName`、`netOpenName`
  - 曲目：`bpm`、`movieName`、`cueName`、`longMusic`（`1` = 長版，吃 2 首）
  - 解鎖：`eventName` / `eventName2` / `subEventName`、`lockType` / `subLockType`
  - 宴會場：`utageKanjiName`、`comment`、`utagePlayStyle`
  - 其他：`disable`
- **每個譜面**（`notesData/Notes`）：`file/path`、`level`、`levelDecimal`、`musicLevelID`（顯示用等級）、`maxNotes`、`isEnable`、`notesDesigner`。
- **自製譜慣例**：
  - `eventName` 用 1（無期限常時解放），歌一開始就能玩。
  - 作者 / 譜師 ID 填 999。
  - MaiChartManager 自己的資料放在 `X-MCM/` 節點（遊戲讀 XML 時會忽略未知節點）。
- **衝突檢查**：不同選項包裡的同名 `music00xxxx.acb/.awb`、`00xxxx.dat` 會互相蓋掉（後讀的勝出，見 [10](10-資源與選項包.md)），所以它會掃描列出來。

## 3. 封面怎麼做

- **官方格式**：400×400 BC7 的 Texture2D AssetBundle。MaiChartManager 把長邊限制在 400。它說明的原因：3000×3000 RGBA32 一張就要 34 MB 顯存，選曲時同步載入會掉幀。
- **不用 Unity 也能產生 AB**：MaiChartManager 自己寫 UnityFS 檔頭（版本 `2018.4.7f1`），把 RGBA32 Texture2D 包進去。container 路徑：
  - 大封面：`assets/assetbundle/jacket/ui_jacket_<id>.png`
  - 小封面：`assets/assetbundle/jacket_s/ui_jacket_<id>_s.png`
- **用 AquaMai 直讀圖片就不用 AB**，見第 4 節。MaiChartManager 判斷封面的優先順序：
  1. `LocalAssets\<非DX ID 6 位>.png/.jpg/.jpeg`
  2. `A???\AssetBundleImages\jacket\ui_jacket_<ID>.png`（「假 AB」）
  3. `.ab`

## 4. AquaMai 的 `LoadLocalImages`（原始碼確認）

設定段 `[GameSystem.Assets.LoadLocalImages]`，預設開啟，設定 `ImageAssetsDir`（預設 `LocalAssets`）。

- **讀取時機**：Prefix `DataManager.LoadMusicBase`，用 Harmony 參數 `____targetDirs` 拿到遊戲的選項包清單（`A???` / `N???`）。
- **掃描的資料夾**：每個包的 `AssetBundleImages\{jacket, frame, nameplate, framemask, framepattern, icon, chara, partner}`、`AssetBundleImages\map\sprite\bg\*`、`Common\Sprites\Tab\Title`。
  - 檔名去掉 `ui_jacket_`、`ui_plate_` 等前綴，後面 6 位數就是 ID。
  - 後讀的包覆蓋前面的。
- **`LocalAssets`**：可以同時在遊戲根目錄和各選項包裡，依檔名合併（`AquaMai.Core.Helpers.LocalAssets`）。封面優先用 `LocalAssets\<ID>.png`。
- **換圖入口**：`TargetMethods` 一次掛多個方法，用 Prefix 回傳自己的 `Texture2D`（`new Texture2D(1,1,RGBA32,false)` + `LoadImage`）：
  - `AssetManager.GetJacketTexture2D(string)`、`GetJacketThumbTexture2D(string)`
  - `GetPlateTexture2D(string)`、`GetFrameTexture2D(string)`、`GetIconTexture2D(string)`
  - 以及 frame mask / pattern、chara、partner 的取圖方法
  - 所以 [10](10-資源與選項包.md#4-動態銘牌ngoplates-的做法) NgoPlates 的 Postfix 拿到的 `__result` 已經是 AquaMai 讀的 PNG。
- **分類標題圖**（`UI_CMN_TabTitle_<ID>`）：
  - 遊戲直接用 `Resources.Load<Sprite>` 載入。AquaMai 原始碼的註解寫：掛泛型 `Resources.Load<Sprite>` 會黑屏，掛 `AssetBundleManager.LoadAsset` 會記憶體錯誤。
  - 所以它改成遊戲載入後自己換 Sprite。MaiChartManager 自訂分類圖時把 `FileName` 設成 `UI_CMN_TabTitle_<ID>`，圖放在 `LocalAssets`。
- **小封面**：沒有 `jacket_s` 圖時，同一張圖也會拿來當小封面（兩個方法掛同一個 Prefix）。

## 5. 影片與音訊

- **PV**：遊戲讀 `MovieData\<非DX ID>.dat`（USM）。
- **AquaMai `MovieLoader`**：
  - 播放順序：遊戲自帶 PV → `MovieData\*.mp4`（或設定的路徑）→ 用封面當背景。
  - 入口：`DataManager.LoadMusicBase`（掃 mp4）、`GameCtrl.Initialize`、`GameMonitor.SetMovieMaterial`、`MovieController.Play` / `GetMovieWidth` / `GetMovieHeight`。
- **MaiChartManager 轉影片**：用 FFmpeg 轉 H264 / VP9，再包成 USM（WannaCRI）。影片不放音訊，音樂在 ACB 裡。
- **音訊**：用 SonicAudioTools / XV2-Tools 產生 `music<非DX ID>.acb/.awb`。格式見 [04](04-音效系統.md)。

## 6. 遊戲資料夾一覽（本機 1.70 `A000`）

`A000` 底下的資料夾就是遊戲所有可以用選項包覆蓋的資料種類：

- **曲目**：`music`、`musicGenre`、`musicVersion`、`musicLevel`、`musicDifficulty`、`musicClearRank`、`musicGroup`、`musicNameSort`、`releasetag`
- **收藏品**：`plate`、`title`、`icon`、`frame`、`partner`、`partnerCloseness`、`photoFrame`、`collectionGenre`、`collectionType`
- **成長與地圖**：`chara`、`charaAwake`、`charaGenre`、`map`、`mapBonusMusic`、`mapColor`、`mapTreasure`
- **活動與挑戰**：`event`、`loginBonus`、`mission`、`missionMusicCondition`、`course`、`courseMode`、`challenge`、`class`、`udemaeBoss`、`udemaeSeasonEvent`、`udemaeSeasonReward`
- **CiRCLE**：`circleBonus`、`circlePointEvent`、`circlePointReward`、`festa`、`festaSide`、`festaRankingReward`
- **KaleidxScope**：`kaleidxScopeCourse`、`kaleidxScopeGate`、`kaleidxScopeGatePhase`、`kaleidxScopeGateExLifePhase`、`kaleidxScopeKey`、`kaleidxScopeMusicGroup`
- **通行證與商店**：`passChara`、`passCharaGroup`、`passPack`、`passType`、`shopItem`、`shopItemCategory`、`ticket`
- **其他**：`hiddenItem`、`information`、`scoreRanking`
- **資源**：`AssetBundleImages`（`chara frame frame_s framemask framepattern fst_image icon jacket jacket_s map nameplate navichara partner passbg passchara photoframe scoreranking specialeffect tabtitle`…）、`SoundData`、`MovieData`、`DataConfig.xml`

## 7. 其他

- MaiChartManager 的「遊戲資源連結」工具：用 Windows Junction 把另一套遊戲的 `AssetBundleImages`、`MovieData`、`SoundData` 連到目前這套的 `A000`，省空間；只連目標不存在的項目，來源只讀。
- AquaMai 安裝位置：`Mods\AquaMai.dll`，設定檔 `AquaMai.toml`（備份 `AquaMai.toml.bak`）。MuMod：`Mods\MuMod.dll`、`MuMod.toml`，快取在 `LocalAssets\MuMod.cache`。
- AquaMai 本身是很大的參考來源（Apache-2.0，可以讀原始碼）。`AquaMai.Mods` 依類別分 `Fix`、`GameSystem`、`GameSettings`、`UX`、`Fancy`、`Tweaks`、`Utils`，還沒逐一研究。
