# 01 遊戲與玩法（遊戲到底在玩什麼）

> 來源：反編譯 SDEZ 1.70（MAGiCAL）`Assembly-CSharp.dll`（標「反編譯」的都核對過），背景資料來自 [RemyWiki](https://silentblue.remywiki.com/maimai_DX:Rating)、[萌娘百科](https://zh.moegirl.org.cn/Maimai_DX)、[4Gamer](https://www.4gamer.net/games/043/G104364/20260917028/)。

## 1. 核心：圓形螢幕 + 8 顆按鈕

- 機台是一個圓形觸控螢幕，外圍有 8 顆按鈕（`Button01`～`08`）。音符從圓心往外飛，到外圈時按對應的按鈕或摸螢幕。兩人並排，各自一台，可以一起玩。
- 音符種類：
  - **Tap**：按一下。
  - **Hold**：按住。
  - **Slide**：先按星星，一拍後沿著軌跡滑。
  - **Touch / Touch Hold**：摸螢幕上的區域，判定區見 `InputManager.TouchPanelArea`，例如 A1～A8、B1～B8、C。
  - **Break**：分數高，要 Critical 才有滿分。
  - **EX**：不是另一種音符，是讓音符發亮的標記；反編譯的 `NotesTypeID.Def` 有 `ExTap`、`ExHold`、`ExSlide`、`ExBreakTap`。
- 難度：BASIC、ADVANCED、EXPERT、MASTER、Re:MASTER，另有宴會場（UTAGE）。同一首歌通常有 STD 和 DX 兩套譜。

## 2. 判定與分數（反編譯 `NoteJudge`、`NoteScore`、`GameScoreList`）

- **判定有 15 段**（`NoteJudge.ETiming`）：`TooFast`、`FastGood`、`FastGreat3rd/2nd/1st`、`FastPerfect2nd/1st`、`Critical`、`LatePerfect`…`TooLate`。畫面上合併成 Critical / Perfect / Great / Good / Miss，另外顯示 Fast / Late。
- **基礎分**（`NoteScore.judgeScoreTbl`）：

| 種類 | Critical / Perfect | Great（3 段） | Good | Miss |
|---|---|---|---|---|
| Tap / Touch | 500 | 400 | 250 | 0 |
| Hold | 1000 | 800 | 500 | 0 |
| Slide | 1500 | 1200 | 750 | 0 |
| Break | 2500 | 2000 / 1500 / 1250 | 1000 | 0 |

  所以權重是 Tap : Hold : Slide : Break = 1 : 2 : 3 : 5。
- **Break 加分**（`EScoreType.BreakBonus`）：Critical 100、Perfect 75 / 50（依 Fast / Late 和第一、第二段而不同）、Great 40、Good 30。
- **達成率** = 基礎分 / 理論基礎分 × 100% + Break 加分 / 理論 Break 加分 × 1%，最高 **101%**（`GameManager.TheoryMaxAchive`）。也就是說，全 Perfect 只有 100%，最後 1% 要靠 Break 打 Critical。
- **DX 分數**：理論值 = 音符數 × 3（`TheoryDxScore = num6 * 3`）。星星門檻是理論值的 85 / 90 / 93 / 95 / 97%（`DeluxcorerankrateIDEnum`）。這個分數衡量的是「Critical 有多少」，和達成率是兩條不同的線。
- **連擊旗標**（`PlayComboflagID`）：None、Silver（FC）、Gold（FC+）、AllPerfect、AllPerfectPlus。另有同步旗標（`PlaySyncflag`，兩人一起玩用）。

## 3. 評級與 Rating（反編譯 `RatingTableIDEnum`、`UserRate`、`UserRating`）

- **評級門檻**（達成率 × 10000）：S 97%、S+ 98%、SS 99%、SS+ 99.5%、SSS 100%、**SSS+ 100.5%**；往下是 AAA 94%、AA 90%、A 80%、BBB 75%…D。
- **單曲 Rating** = ⌊定數 × 10 × min(達成率, 100.5%) × 係數 / 10⁸⌋ + AP 加分：
  - 定數 × 10 = `notes.level * 10 + notes.levelDecimal`。
  - 係數（× 10）：SSS+ 224、SSS 216（100.4999% 是 222）、SS+ 211、SS 208、S+ 203、S 200、AAA 168…，前一級的上限有自己的係數（例 `Rate_21` 100.4999% = 222）。
  - AP / AP+ 再 +1（`UserRating.ApBonusTable`）。
  - 例：定數 14.5 打 SSS+ → 145 × 1005000 × 224 / 10⁸ = 326。
- **總 Rating** = 舊曲最好的 **35 首**（`RatingList`）+ 新曲最好的 **15 首**（`NewRatingList`）。新舊用 `romVersion < 26500` 區分（`UserRate.OldFlag`）。
- 所以玩家的長期目標是「把高定數的歌推到 SSS+」：100.5% 以上就不再加 Rating，之後追的是 AP 和 DX 分數星星。

## 4. 一次遊玩的流程

- 投幣 / 刷卡 → `EntryProcess` → 資訊、登入獎勵（`LoginBonus`）、禮物 → 模式選擇（`ModeSelect`）→ 地區 / 地圖（`RegionalSelect`）→ 旅行夥伴（`CharacterSelectProces`）→ 功能票（`TicketSelect`）→ **選曲 → 打歌 → 結算**，重複數首（首數依店家設定與功能票，未研究）→ 地圖結算（`MapResultProcess`）→ 上傳（`UserDataULProcess`）。
- **自由模式**（Freedom）：以時間計，不限首數（反編譯有 `FreedomModeMusicSelectTimerShowTime`）。
- **功能票**（`TicketData`、`TicketEvent`）：效果未研究；MAGiCAL PASS 會送「+1 首」票（`MagicalpassIDEnum`）。

## 6. 一句話總結

maimai 的「玩」有三層：
- **當下**：跟著節奏用手拍、滑、摸。手在圓上移動的路線本身就是樂趣，Slide 和左右手交叉是特色。
- **一首歌**：達成率（準不準）、DX 分數（Critical 多不多）、連擊三條線。
- **長期**：Rating（推高定數歌到 SSS+）、收集（地圖、夥伴、收藏品）、社交（雙人、友人對戰、店內連線）。
