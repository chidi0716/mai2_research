# 10 資源與選項包（StreamingAssets、收藏品、貼圖、換皮）

> 來源：反編譯 SDEZ 1.70 `Assembly-CSharp.dll`（標「反編譯」的都核對過）、NGO 铭牌包（`NgoPlates.dll` 反編譯 + 資料檔）、[maimai-ngo](https://github.com/TOTO-git-q/maimai-ngo) 的說明文件。標「NGO 實測」的是對方記錄的量測結果，我們沒有自己重現。

## 1. 選項包資料夾（`A???` / `N???`）

反編譯 `DataManager.GetDirs`、`IsTargetDirName`：

- 遊戲掃 `Sinmai_Data\StreamingAssets\` 底下名稱符合 `A???` 的資料夾：**`A` + 3 位數字**（`int.TryParse` 後面 3 個字元），排序後依序讀。
- 接著掃 `AppImage.OptionMountRootPath` 底下的 `N???`（排序後接在 `A???` 後面）。原版的值沒在 `Assembly-CSharp` 裡確認；裝了 AquaMai 時，`OptionLoadFix`（預設開）把它改成 `StreamingAssets` 本身，所以 `StreamingAssets\N???` 也會被讀（見 [14](14-AquaMai功能與入口.md)）。
- 例：本機 1.70 有 `A000`（本體）、`A100`、`A999`、`N100`、`N999`。
- **後面的資料夾覆蓋前面的**：
  - XML 資料（`LoadData`）以 ID 為鍵，`outSerializes[id] = ...`，同 ID 後讀的勝出；`disable = true` 的條目最後被移除。
  - 影片（`MovieData\*.dat`）、音效（`SoundData\*.awb`、`Mai2.acf`）以檔名為鍵，後讀的勝出。
  - AssetBundle（`AssetBundleImages\**\*.ab`）以 `AssetBundleImages/` 之後的相對路徑為鍵，後讀的勝出。
- `DataConfig.xml`：每個資料夾都可以有一份，取 `version` 最大的那份（反編譯 `SetupConfig`）。
- 所以加內容 = 新開一個編號沒被用掉的 `Axxx`，放同樣的子資料夾結構，不動原檔。NGO 銘牌包用 `A588`，maimai-ngo 的搭檔資料用 `A500`。

## 2. 收藏品 XML（以銘牌為例）

- 路徑：`A???\plate\plate<6 位數 ID>\Plate.xml`（排序檔 `plate\PlateSort.xml`）。其他收藏品同理：`partner\partner<ID>\Partner.xml`、`title`、`icon`、`frame`。
- 根元素 `PlateData`，主要欄位：`dataName`、`netOpenName`、`releaseTagName`、`disable`、`eventName`（{id, str}）、`name`（{id, str}，id 就是銘牌 ID）、`genre`（例 5 = その他）、`isDefault`、`dispCond`（`None` / `Lock` …）、`normText`（鎖住時顯示的說明）、`relConds`（解鎖條件）、`priority`。
- **貼圖檔名是遊戲自己決定的**（反編譯 `DataManager.LoadPlate`）：`fileName = "NamePlate/UI_Plate_" + id.ToString("D6") + ".png"`，XML 裡的 `<fileName>` 沒有作用。
- **收藏畫面顯示規則**（反編譯 `CollectionProcess`）：玩家擁有，或 `dispCond == None`，或 `disable` 時才列出；ID 2、3 是固定的「預設 / 隨機」項目。

### 讓自訂收藏品「打一首歌就自動解鎖」

NGO 銘牌包的做法（已用反編譯驗證）：

- `eventName.id = 1`（「無期限常時解放」），`relConds.category = Track`，`condition0.kindTrack = DIFFICULTY`、`difficultyId = ANY`，其餘條件 `None`。
- `CollectionAchieve.Configure` 收集 `relConds` 裡有 Track / Credit / Total 條件的銘牌、稱號、icon、搭檔、frame，以 `eventName.id` 分組；`Initialize` 只保留 `EventManager.IsOpenEvent(eventId)` 的事件。
- 每首歌結束時 `NextTrackProcess` 呼叫 `CollectionAchieve.BuildParameter` → `CheckNewPlate` / `CheckNewTitle` …。`AchieveTrack.FuncDifficulty` 遇到 `ANY` 直接回傳 true，所以任何難度打完一首就拿到。
- 好處：不用 Harmony，走遊戲自己的取得流程（有「NEW」標記）；壞處：取得紀錄會上傳到伺服器。

## 3. 貼圖怎麼載入

- `AssetManager` 建構時把 `StreamingAssets/A000/AssetBundleImages/` 交給 `AssetBundleManager`；實際的 bundle 路徑由 `OptionDataManager.GetAssetBundlePath` 決定（第 1 節的覆蓋規則）。
- `AssetManager.LoadAsset<T>(path)`：路徑先轉小寫，去掉副檔名後查快取的 bundle（反編譯）。
- 取圖方法（反編譯）：

| 方法 | 找不到時 |
|---|---|
| `GetPlateTexture2D(int id)` → `GetPlateTexture2D(string filename)` | `NamePlate/UI_Plate_000000.png` |
| `GetFrameTexture2D(int)` / `(string)` | `Frame/UI_Frame_000000.png` |
| `GetPartnerTexture2D(int)` / `(string)` | `Partner/UI_PartnerIcon_000000.png` |
| `GetIconTexture2D(string)` | `Icon/UI_Icon_000000.png` |

  `int` 版本：`DataManager.GetPlate(id)` 為 null 時，隨機項目（`GameCommonSetting.IsRandom(id)`）用 `..._00000{id}.png`，否則用預設圖。
- 遊戲本身只讀 `*.ab`。直接放 PNG（`AssetBundleImages\nameplate\ui_plate_990001.png`）要靠 **AquaMai 的 `[GameSystem.Assets.LoadLocalImages]`**（AquaMai 原始碼已確認：Prefix `GetPlateTexture2D(string)` 等取圖方法，直接 `LoadImage` 讀 PNG，見 [13](13-自製譜與選項包管理.md#4-aquamai-的-loadlocalimages原始碼確認)）。
- **小方法會被 Mono JIT 內聯**（NGO 實測）：例如 `GetPartnerTexture2D(string)` 從 `(int)` 版本被呼叫時，掛在 `(string)` 上的補丁不會觸發。要掛呼叫端真的用的那個多載，或往下一層掛比較大的方法。NgoPlates 掛 `GetPlateTexture2D(string)` 的 Postfix 能用，是因為其他地方直接用檔名呼叫它（實測可用；內聯的條件沒有逐一確認）。

## 4. 動態銘牌（NgoPlates 的做法）

銘牌本身仍是靜態 PNG（第 2、3 節），mod 只負責讓它動：

- **入口**：Postfix `AssetManager.GetPlateTexture2D(string filename)`（`[HarmonyPriority(0)]`，排在其他 Postfix 之後），用正規式 `UI_Plate_(\d+)\.png` 取 ID，有動畫資料就把 `__result` 換成自己的 `Texture2D`。之後每幀用 `Graphics.CopyTexture(下一格, 那張貼圖)` 改內容；遊戲手上的引用不變，所以不用找 UI 物件。
- **畫格格式**：原始 BC7 區塊直接接在一起（沒有檔頭），一格 720×116 → (720/4)×(116/4)×16 = **83,520 bytes**；檔案長度必須是它的整數倍。`new Texture2D(720, 116, TextureFormat.BC7, false)` + `LoadRawTextureData(ptr, 83520)` + `Apply(false, true)`。Unity 的原始資料列是**由下往上**。
- **載入**：背景執行緒只讀檔（`File.ReadAllBytes`），主執行緒每幀做幾格貼圖（打歌中 2 格、其他 8 格），全部做好才開始播。啟動時檢查 `SystemInfo.SupportsTextureFormat(BC7)` 與 `copyTextureSupport`，不支援就維持靜態。
- **切換狀態**：Postfix `ProcessManager.AddProcess(ProcessBase, byte)`，看 `process.GetType().Name`：`GameProcess` → 打歌狀態；`MusicSelectProcess`、`EntryProcess`、`AdvertiseProcess` → 一般狀態。12 fps，用 `Time.unscaledTime` 計時。
- **開關**：補丁類別的 `Prepare()` 回傳「資料夾存在」，刪掉 `LocalAssets\NgoPlates` 就整個不掛。任何例外 → 停用並保留目前畫面，不讓遊戲崩。

## 5. 直接改遊戲資源檔（maimai-ngo 換皮的做法）

maimai-ngo 的外觀幾乎都是寫進遊戲檔案，不是執行期替換（執行期替換會先閃一下原圖，而且每幀都有成本）。以下為 NGO 實測：

- **位置**：UI 貼圖、Sprite（網格、rect）、`Image` 顏色、Prefab 數值、材質、粒子、3D 選單背景都在 `Sinmai_Data\resources.assets`（+ `.resS`）；導航角色（結算 / 選曲的熊）、角色圖在 `StreamingAssets\A000\AssetBundleImages\...\*.ab`（例 `navichara\prefab\ui_navichara_00.ab`、`chara\ui_chara_<id>.ab`）；分類顏色等在 StreamingAssets 的 XML。
- **工具**：UnityPy（`TypeTreeGenerator("2018.4.7f1")` + `load_local_dll_folder(Managed)` 才讀得到 MonoBehaviour）。
  - 要讀**遊戲資料夾裡那份**，備份檔在別處時外部參照會斷。
  - 同一個物件一次執行只能讀改存一次（第二次會從原始檔重讀，蓋掉第一次的修改）。
  - UnityPy 是延遲讀取：先 `env.file.save()` 產生完整輸出，寫成 `.new`、檢查大小，再在遊戲關閉時覆蓋。
  - 貼圖保持原名、原尺寸、原格式；像素會從 `.resS` 搬進 `.assets`（約 67 MB → 175 MB）。BC7 編碼用 `etcpak`，解碼用 `texture2ddecoder.decode_bc7`（`etcpak.decompress_bc7` 在他們的環境會失敗）。
- **畫之前先看原格式**：
  - 很多面板貼圖是白色遮罩，顏色由 `Image.color` 或程式上色；在上色的貼圖畫彩色會變髒，要改的是顏色。
  - 9-slice 的邊框列要照原本的保留。
  - 原版 Sprite 的網格是沿著原圖描邊的，換成形狀不同的圖會被裁掉，要改成整張四邊形或放大 `textureRect`。
  - 選中分頁是「彩色底圖 + 白色剪影疊圖（遊戲調它的 alpha 做閃爍）」兩層。
  - `Null_Selector_ColorBase._colors` 依難度索引，只有 index 7（分類藍 `#0A87F0`）可以改，其他是難度色。這是資源物件，`Assembly-CSharp` 裡沒有同名類別。
- **會出事的修改**：改 Sprite 的 `m_SortingLayer` 會讓待機畫面崩潰（要調順序請改材質 render queue，例如 2450）；MeshRenderer 的 sorting layer 改了沒效果。
- **3D 背景**：原版 Loop 動畫不驅動任何 Transform，「飄動」來自 shader 與粒子；要動就調粒子系統。
- **字型**：Unity 2018 不能從硬碟載 TTF；他們把像素字型的位元組寫進遊戲的 LiberationSans Font 物件，再在 `TextMeshProUGUI.OnEnable` 建動態 SDF 字型。
- **發布方式**：安裝器逐個物件核對原值（`old`）再寫新值（`new`），不符就不寫；先備份（含 SHA-256），可重複執行、可解除安裝。這樣 repo 裡不必放遊戲檔案。

## 6. 執行期換圖的入口（maimai-ngo，各入口已用反編譯確認存在）

| 時機 | 入口 | 用途 |
|---|---|---|
| 換畫面 | `ProcessManager.AddProcess(ProcessBase, byte)` Postfix | 判斷目前畫面（比 `OnStart` 早一步，一個入口就涵蓋全部 Process） |
| 待機 | `AdvertiseProcess.OnUpdate` | 加速 SEGA / ALL.Net 標誌（直接略過的話標題畫布不會出現，畫面變黑） |
| 任何 `Image` | `Image.OnEnable`、`Image.OnPopulateMesh`、`Image.sprite` setter | 換圖、頂點上色（給程式上色的貼圖） |
| 任何 TMP 文字 | `TextMeshProUGUI.OnEnable` | 換字型 |
| 選單背景 | `BGController.Awake`、`SubBGController.Initialize(int, bool)` | 換背景 |
| 選曲 | `MusicSelectProcess.OnStart/OnUpdate/OnRelease`、`SoundManager.PreviewPlay(int)`、`MusicSelectMonitor.ScrollMusicLeft/Right` | 版面、搭檔反應 |
| 隱藏店內匹配分類 | `MusicSelectProcess.SetConnectData` 後拿掉該分類、`IsConnectStart` / `IsConnectStop` 回「沒變化」 | **不可以略過 `PartyExec`**：NORMAL 模式是靠它把 START 轉成開始打歌 |
| 自由模式倒數 | `PleaseWaitMonitor.SetTime(int, int)` | 隱藏 / 換掉凍結的 10:00 |
| 歌曲開始卡片 | `TrackStartProcess.OnStart` | 換動畫 |
| 結算 | `ResultMonitor.SetStartData`、`TouchPartnerCharacter()`、`ResultTimelineManager.SetData` | 搭檔、評級動畫 |
| 導航角色動畫 | `NavigationCharacter.Play(NavigationAnime, float)` | 把原版狀態對應到自己的動作 |
| 搭檔房間 | `PartnerRoom.CreatePartner(int partnerId)` | 自訂搭檔 |
| 上傳畫面 | `UserDataULProcess.OnStart` | 隱藏 `DataSave/Chara`（隨機吉祥物都在這個群組） |
| 觸控 | `IO.TouchPanel.GameInputLog.TriggerOn(uint, InputManager.TouchPanelArea)`（internal，用 `AccessTools.TypeByName`） | `InputManager.GetTouchPanelAreaDown` 太小會被內聯 |

自訂搭檔另見 [08](08-加入自訂內容.md#5-伙伴旅行伙伴動畫)：
- 新搭檔要在 `A500\partner\partner<ID>\Partner.xml` 加資料（UTF-8 含 BOM、`isDefault = true`、`dispCond = None`），只在遊戲啟動時讀。
- 新的 `naviChara` ID（≥ 29）沒有 Prefab，遊戲會退回原版導航角色，要自己藏起來（NGO 實測）。
