# 09 遊戲流程與即時狀態讀取

整理自 maimai-dghub-link（XiaoLanMaiBrdge，見 [06](06-參考專題.md)）的原始碼：怎麼知道玩家現在在哪個畫面、打歌中的每一個判定、成績、選曲倒數、遊戲版本與玩家名稱。這些入口不限於某一種 mod，做顯示、聯動、統計、改畫面時都用得到。

> 型別名稱用 `AccessTools.TypeByName("完整名稱")` 取得，找不到時就停用該功能，不要讓 mod 崩潰。以下名稱在 SDGB 1.50 / 1.55、SDEZ 1.60 / 1.65(1.66) 都存在（該專題做過成員級檢查）。

## 1. 畫面（Process）一覽

遊戲每個畫面是一個 Process。對它的 `OnStart` / `OnRelease` 掛 Postfix，就能知道「現在進到 / 離開哪個畫面」，並拿到該 Process 的實例（`__instance`）。

| 完整型別名稱 | 畫面 | 備註 |
|---|---|---|
| `Process.AdvertiseProcess` | 待機宣傳畫面 | |
| `Process.AdvertiseCommercial.AdvertiseCommercialProcess` | 待機廣告 | |
| `Process.EntryProcess` | 刷卡 / 登入 | |
| `Process.PlInformationProcess` | 登入後的玩家資訊 | `RestoreGhost` 在這裡（閃退熱點，見 [05](05-踩坑紀錄.md)） |
| `Process.InformationProcess` | 公告資訊 | |
| `Process.GetPresentProcess` | 領取禮物 | |
| `Process.ModeSelect.ModeSelectProcess` | 模式選擇 | |
| `Process.RegionalSelectProcess` | 地圖（區域）選擇 | |
| `Process.CharacterSelectProces` | 角色選擇 | **類別名稱少一個 s**，是遊戲原本的拼法 |
| `Process.TicketSelect.TicketSelectProcess` | 功能票選擇 | |
| `Process.MusicSelectProcess` | 選曲 | 見 [03](03-遊戲內部結構.md) |
| `Process.MusicSelectInfoProcess` | 選曲後的確認 / 讀取 | |
| `Process.GetMusicProcess` | 取得新曲 / 讀取 | |
| （打歌中） | | 用 `GameManager.IsInGame` 判斷 |
| `Process.ResultProcess` | 結算 | |
| `Process.CodeReadProcess` | DX PASS 讀卡 | 見 [08](08-加入自訂內容.md) |

- 兩種掛法：知道型別時用 `[HarmonyPatch(typeof(X), "OnStart")]`；要跨版本容錯時用 `AccessTools.TypeByName` 加 `harmony.Patch`，同一個 Postfix 可以掛在好幾個 Process 上，再用 `__instance.GetType().FullName` 分辨是哪一個。
- `OnRelease` 時只在「離開的就是我記住的那個實例」時才清掉（`ReferenceEquals`），避免新舊畫面交錯時清錯。
- 部分 Process 會按玩家數各觸發一次，記得去重。

## 2. 打歌中的每一個判定

```csharp
var original = AccessTools.Method(typeof(JudgeResultSt), "UpdateScore",
    new[] { typeof(int), typeof(NoteScore.EScoreType), typeof(NoteJudge.ETiming) });
harmony.Patch(original, postfix: new HarmonyMethod(typeof(MyMod), nameof(JudgePostfix)));

// 參數名稱照原方法: monitorIndex(玩家索引 0/1)、type(音符計分種類)、timing(細分的判定時機)
static void JudgePostfix(int monitorIndex, NoteScore.EScoreType type, NoteJudge.ETiming timing)
{
    switch (NoteJudge.ConvertJudge(timing))   // 把細分時機收斂成五級
    {
        case NoteJudge.JudgeBox.Critical: break;
        case NoteJudge.JudgeBox.Perfect:  break;
        case NoteJudge.JudgeBox.Great:    break;
        case NoteJudge.JudgeBox.Good:     break;
        case NoteJudge.JudgeBox.Miss:     break;
    }
}
```

- 這是**遊戲自己計分的入口**，每個音符判定都會經過，比每幀輪詢分數準，也不會漏。
- 它在遊戲主執行緒執行，Postfix 裡只做計數，推送 / 寫網路交給其他執行緒。
- 不解析網路封包、不讀觸控輸入，所以不受私服設定或 AquaMai 改網路的影響。
- Combo 可以自己算（Miss 歸零、其他 +1），也可以從 `GameScoreList` 讀。
- `GameManager.MusicTrackNumber`：目前第幾首（track），用來分辨換歌。

## 3. 正在打的譜面與進度

```csharp
// NotesManager 是每個玩家一個實例: 靜態方法 Instance(int player)
var nm      = NotesManager.Instance(player);
var session = nm.GetSessionInfo();          // musicId, difficulty, notesData
var now     = NotesManager.GetCurrentMsec(); // 目前播放到幾毫秒(靜態方法, 兩個玩家共用)
var first   = nm.getPlayFirstMsec();        // 譜面開始的時間點(小寫 g 開頭, 遊戲原本的拼法)
var last    = nm.getPlayFinalMsec();        // 譜面結束的時間點
```

- `session.musicId` + `DataManager.GetMusic(id)` 取得曲名、藝術家；`session.notesData` 是這個難度的 `Notes`。
- 難度：0 BASIC、1 ADVANCED、2 EXPERT、3 MASTER、4 Re:MASTER、5（以上）宴會場。
- 進度 = `(now - first) / (last - first)`，可以拿來做進度條或依時間觸發效果。

## 4. 分數與成績

| 來源 | 內容 |
|---|---|
| `GamePlayManager.Instance.GetGameScore(player, -1)` | 目前這首的 `GameScoreList`（`-1` = 目前的 track） |
| `GameScoreList` | `CriticalNum`、`PerfectNum`、`GreatNum`、`GoodNum`、`MissNum`、`Combo`、`MaxCombo`、`DxScore`、`IsEnable`、`SessionInfo`；達成率 `GetAchivement()`（**遊戲原本拼錯**，少一個 e；保險起見兩種拼法都試） |
| `ResultProcess` 私有欄位 `_gameScoreLists[player]` | 結算畫面的成績 |
| `ResultProcess` 私有欄位 `_userScores[player]` | 玩家存檔裡的成績（有 `deluxscore`，拼法如此） |
| `ResultProcess` 私有欄位 `_musicID` | 結算的曲目 ID |

- `IsEnable == false` 表示這個玩家位置沒有在玩（單人時的另一側）。
- 結算畫面的資料在 `OnStart` 當下可能還沒填好，要在之後幾幀重讀，直到數值不再變化。

## 5. 選曲畫面的「目前選到哪首」

- `MusicSelectProcess` 的目前卡片 → `CombineMusicSelectData.musicSelectData[ScoreType].MusicData`（見 [03](03-遊戲內部結構.md)）。
- 曲目 ID 讀 `MusicData` 的 `id`（部分版本要讀 `name.id`）。
- 目前難度：`MusicSelectProcess.CurrentDifficulty[p]`，或靜態 `GameManager.SelectDifficultyID[p]` / `GameManager.CurrentDifficulty[p]`。
- 顯示用等級（例如 `13+`）：`Notes.musicLevelID` → `DataManager.GetMusicLevel(id).levelNum`；定數仍是 `level + levelDecimal / 10`。
- 要確認該難度存在：`Notes.musicLevelID > 0` 或 `level > 0`。

### 宴會場（UTAGE）判斷

符合任一條件即為宴會場：

- `MusicData.genreName.id == 107`，或分類名稱含「宴會場 / 宴会场」
- 曲目 ID `>= 100000`，且 `utageKanjiName`（宴、協、狂…）不是空的，或曲名以 `[` 開頭

宴會場的譜面放在 `notesData[0]`，顯示名稱用 `"UTAGE " + utageKanjiName`。

## 6. 畫面倒數計時

選曲、地圖、角色等畫面右上角的倒數，讀法（依序嘗試）：

```
process.container.processManager._genericManager._timerController[0]
    .CountDownSecond   // 剩餘秒數
    .IsInfinity        // 是否無限時間(Free Play / 設定關閉計時)
```

找不到時往下找：Process 本身的 `_timer` / `Timer` / `_monitor_timer` / `MonitorTimer`，或 `Monitors[0]`，或 `Context.GetCurrentState()` 拿到目前狀態物件再找同名成員（最多 5 層）。

用途：顯示剩餘時間；快到 0 時不要做跳轉之類會跟遊戲搶狀態的動作。

## 7. 遊戲版本、玩家名稱、登入狀態

```
// 顯示版本(例: "Ver.CN1.56-B")
MAI2System.SystemConfig.Instance.config.displayVersionString
// 退而求其次
MAI2System.SystemConfig.Instance.config.romVersionInfo.versionNo.versionString
Manager.AmManager.Instance.VersionNo.versionString
```

- 玩家：`Singleton<UserDataManager>.Instance.GetUserData(i)`，`IsEntry` 是否登入，名稱在 `Detail.userName`（部分版本是 `UserName`）。
- 網路側：`Manager.NetDataManager.Instance.GetNetUserData(i)`。
- 未登入時名稱可能是空字串、`GUEST` 或「游客」，比對前先做 `Normalize(NormalizationForm.FormKC)`。
- 開機、登出過程中這些都可能是 null，讀取要包 try/catch，且限制重試頻率（例如每秒一次）。

## 8. 寫法上的經驗

- **跨版本反射**：同一個成員依序試多個名稱（`"_gameScoreLists", "gameScoreLists", "GameScoreLists"`），欄位和屬性都試；讀不到就省略該欄位，不要整個失敗。
- **快取**：`MethodInfo`、`FieldInfo`、整數索引器（`GetProperty("Item", new[] { typeof(int) })`）查一次就存起來；`IList` / `Array` 直接用索引。
- **節流**：非打歌畫面的狀態每 250～1000 毫秒讀一次就夠，判定則由 Hook 即時觸發。
- **量測**：用 `Stopwatch` 量每段主執行緒工作，超過門檻就寫一筆警告（同類訊息限制頻率），方便找出拖慢遊戲的地方。
- **只跑一份**：用具名 `System.Threading.Semaphore(1, 1, "名稱")` + `WaitOne(0)` 防止同一個 mod 被重複載入兩份（例如新舊檔名並存）。
- **本機推送**：SSE 伺服器用 `TcpListener(IPAddress.Loopback, port)` 自己寫，收連線和送資料各一條專用執行緒；只聽 127.0.0.1 就不會暴露到區網。

- **機台按鈕 LED**：
  - `IO.MechaManager.LedIf[monIndex]`（`Mecha.Bd15070_4IF`，每個玩家一塊板子）提供 `SetColor(byte ledPos, Color32 color)`、`SetColorFet(byte ledPos, byte)`、`GetLedAnimeSpeed()`；`MechaManager.SetAllLEDOff()` 全部熄燈。
