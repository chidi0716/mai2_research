# 06 參考專題

## 1. maimai-song-request-（原作點歌 mod）

- 作者：[ZCM-X](https://github.com/ZCM-X/maimai-song-request-)（MIT）
- 分析過的版本：v1.0.3（DLL + 說明檔，反編譯）、v1.0.4～v1.0.7（原始碼）
- 功能：本機網頁點歌、曲目表從遊戲讀取、點難度直接跳轉、正在遊玩面板
- 參考到的重點：
  - **就緒門控**：`DataManager.IsLoaded()` 前不碰遊戲物件（修登入閃退）
  - **崩潰保護**：`RestoreGhost`、`CategoryTabGenre/Sort` 加 Finalizer，`GetUdemaeBoss`、`GetMusicGenre` 加兜底（後來改預設關閉）
  - v1.0.5 併入 chidi0716 fork 的穩定性修正（SSE 寫入執行緒、曲目表並行、點歌狀態機）
  - v1.0.6 修正 DX 譜點歌（依點的那套決定 `ScoreType`）
  - v1.0.7 效能：便宜的曲庫變化偵測、JSON 片段快取、跳轉期間暫停重活、`/api/perf`、封面快取 key

## 2. 扫码点歌（SongSearch）v1.1.1

- 作者：[Clansty](https://github.com/clansty)（未標明授權，只參考做法，不複製程式碼）
- 功能：手機連 `電腦IP:8081` 點歌，作者建議把網址做成 QR code 或 NFC 貼紙
- 架構：核心約 200 行；網頁伺服器用 WatsonWebserver（直接聽 `0.0.0.0`）；前端 Vue 3 + Naive UI；曲名和社群別名寫死在網頁裡
- 參考到的重點：
  - **Harmony 參數注入**讀私有欄位（`____combineMusicDataList` 等）
  - `Notes.levelDecimal`（定數小數）、`Notes.notesDesigner`（譜師）
  - DX 判斷用「點的 ID」（`id >= 10000`），方向是對的
- 不建議學的：在網頁執行緒直接操作遊戲（包括 `StartCoroutine`）、曲繪從外部網站抓、用 `GetMusics()` 讀曲目（會被其他 mod 過濾）、跳轉時不檢查遊戲狀態

## 3. 冰冰冰正解音切換（AnswerSoundSwitch）v1.1.0

- 作者：Hematemesis-V
- 環境：Sinmai.exe（Mono x64）、MelonLoader 0.6.4；只在特定 `Assembly-CSharp.dll`（SHA-256 `3152E433…11847A4`）驗證過
- 功能：F8 切換正解音為「冰冰冰」；音量 `IceGain` 1.0～2.0（`MelonPreferences`）
- 檔案：`Mods\AnswerSoundSwitch.dll` + `Mods\AnswerSoundSwitch\Ice\Mai2Cue.acb/.awb`
- 做法：載入整套替換音效為第 6 號音效庫 → Prefix `SoundCtrl.Play` 把正解音（AcbID 0 / Cue 88）轉向第 6 號 → Postfix `CriAtomExPlayer.SetCue` 調音量（細節見 [04](04-音效系統.md)）
- 安全性：程式只有 5 個檔案，不連網，只寫 `MelonPreferences.cfg`

## 4. DxPassCompat v2.4.0（說明檔標 v2.5）

- 作者：ZCM-X（同點歌 mod 原作者）；只有 DLL，反編譯分析
- 功能：舊 DX PASS 卡面（SDED 印的）在遊戲內不顯示的修正、DX PASS 畫面從只能看兩張改成可逐張翻看、全解本機卡面、自製卡面（放圖片就能當卡用）
- 設定：`Package\DxPassCompat.toml`（`[DxPass] UnlockAll`、`[Custom] EnableLocalCards / ImageDir / CardType / CharaId`、`[Card.N]` 逐張設定）
- 參考到的重點：
  - 大量 Prefix 直接接管讀卡畫面 `CodeReadProcess` 的判斷（`IsInPeriod`、`IsDisable` 一律放行）
  - 自訂 ID 範圍 `9000000+`、反射複製 `CardTypeData`、`Texture2D.LoadImage` → `Sprite.Create` 載入圖片
  - `HarmonyLib.Traverse` 讀私有欄位（`_readCardChainList`）
  - Postfix 改 getter 回傳物件的唯讀屬性（反射呼叫私有 setter）
- 細節見 [08 加入自訂內容](08-加入自訂內容.md)

## 5. MaiL2d v1.3.0（Live2D 旅行伙伴）

- 作者：Clansty（同扫码点歌）；**附原始碼，GPLv3**（修改後散布要附原始碼）
- 功能：在「選擇收藏品」頁面選 Live2D 模型當旅行伙伴；只在本機有效、不同步到伺服器；v1.2.0 起支援同名 ACB 語音包
- 檔案：`Mods\MaiL2d.dll` + `LocalAssets\MaiL2dModels\*.mail2dpack`；附 Unity 2018.4.7f1 模型範本專案、語音包範例、Excel 手冊
- 技術重點：
  - `[assembly: HarmonyDontPatchAll]` + `HarmonyInstance.PatchAll(typeof(某類別))`：自己挑要掛哪些補丁類別
  - 負數 ID 代表自訂伙伴；`DataManager.GetPartners` Postfix 加入資料、`CollectionData.IsHave` getter 回 true
  - `AssetManager.GetNaviCharaPrefab` / `GetPartnerTexture2D` Prefix 回傳自訂 Prefab / 圖示
  - `VOExtensions.Export` 兩個方向的 Postfix：自訂選擇不上傳伺服器，存在 `PlayerPrefs`
  - `SoundManager.GetPartnerVoiceCueName` 回傳自訂 ACB 路徑
  - `NavigationCharacter.NaviAnimator` getter、`ResultMonitor.SetStartData` / `TouchPartnerCharacter` 控制 Animator 參數
  - 內嵌原生 DLL（`Live2DCubismCore.dll`）第一次啟動寫到 `Sinmai_Data\Plugins`；內嵌 AssetBundle 用 `LoadFromStream` 載入
  - 用 `MelonLoader.TinyJSON` 讀 JSON
- 細節見 [08 加入自訂內容](08-加入自訂內容.md)

## 6. murasame（MaiL2d 角色包）

- 給 MaiL2d 用的第三方角色包：`murasame.mail2dpack`（AssetBundle，`UnityFS`）+ `murasame.acb/.awb`（語音包）
- ACB 名稱 `murasame`，92 個音效（`VO_000080`～`VO_000254`），與官方伙伴語音同結構；HCA 編碼，部分聲音內嵌在 ACB（memory AWB 約 1.4MB），其餘在 `.awb`
- 用途：模型包 + 語音包的實際成品範例

## 7. maimai-dghub-link（XiaoLanMaiBrdge）v1.4.10

- 作者：[XiaoLan9999](https://github.com/XiaoLan9999/maimai-dghub-link)（**GPLv3**，附原始碼；只參考做法，不複製程式碼）
- 功能：把打歌中的即時判定、結算成績、目前畫面（待機 / 登入 / 選曲 / 結算…）透過本機 SSE（`127.0.0.1:8891/events`）推給 DGHub 外掛，再觸發外部裝置
- 組成：MelonLoader mod `XiaoLanMaiBrdge.dll`（C#，單檔約 2,800 行）+ DGHub 外掛（Python：安裝器、更新檢查）+ 測試（SSE 伺服器測試台、安裝流程、版本相容編譯檢查）
- 參考到的重點（細節見 [09](09-遊戲流程與狀態讀取.md)）：
  - 判定入口 `JudgeResultSt.UpdateScore` Postfix + `NoteJudge.ConvertJudge`：事件驅動，不必輪詢
  - `NotesManager.GetSessionInfo()`、播放毫秒數 → 正在打的譜面與進度
  - 十多個 Process 的 `OnStart` / `OnRelease` → 目前畫面狀態
  - 畫面倒數：`processManager._genericManager._timerController[0].CountDownSecond`
  - 版本字串 `SystemConfig.config.displayVersionString`、玩家名稱、`ResultProcess._gameScoreLists`
  - 跨版本：`TypeByName` + 多個候選成員名稱 + 反射快取；在 SDGB 1.50 / 1.55、SDEZ 1.60 / 1.65 做過成員級檢查
  - 具名 `Semaphore` 防止重複載入；`Stopwatch` 量測主執行緒工作
  - 安裝器：只在遊戲沒執行時寫入、SHA-256 驗證、備份舊檔、保留使用者設定、遷移舊檔名
- 一樣是 Harmony + 本機 SSE，沒有新的接入技術，但遊戲入口很完整
